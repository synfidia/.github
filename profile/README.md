## About Synfidia

Synfidia is a home for open-source work across AI, data, and robotics.

We share practical tools, examples, and documentation as they become ready for public use.

## Projects

Public projects will be listed here as they are released. Check each repository for setup instructions, project status, and its license.

## How to contribute

Contributions are welcome when projects are published. Start with the repository README and contribution guidelines.

- Report bugs with reproducible steps and relevant environment details.
- Discuss substantial changes in an issue before opening a pull request.
- Improve documentation, examples, and tests.
